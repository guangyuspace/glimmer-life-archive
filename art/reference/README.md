# 微光角色參考

這個資料夾保存新版美術生成的核心參考圖。

- `character_reference_grandfather.png`：外公晚年角色設定稿，包含正面、側面與手部。
- `age_sheet_grandfather.png`：同一位外公從少年、青年、中年到晚年的年齡表。

後續生成 `panel_001.png` 到 `panel_018.png` 時，應先引用這兩張作為角色一致性基準，再套用每一幕的分鏡 prompt。

## QA 備註

- 可辨識特徵：眉骨、鼻梁、薄唇、耳型、晚年眼神。
- 年齡連續性：少年到晚年的骨相大致連貫。
- 風格：水彩、淡墨線稿、低飽和、微金色光點，符合《微光》的安靜敘事方向。
- 風險：正式 panel 仍要逐張檢查，尤其兒童期與晚年期最容易跑臉。
